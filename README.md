# 博士学位论文答辩秘书经验指南

## 这是谁写的

吕万里博士，先后担任过五位博士生、一位硕士生的答辩秘书。以下内容基于本人经历，结合王之恒博士、耿晶博士、郝艺伟博士的宝贵经验整理，供后续担任答辩秘书的同学参考。

## 关键时间

- **预答辩** 与正式答辩之间应间隔至少 **两周**，给答辩人留足时间根据预答辩反馈修改 PPT 和论文
- **正式答辩** 须在每年 **5 月 30 日前** 完成（兰州大学规定）

## 总则

本指南依据《兰州大学研究生学位论文答辩要求》（[全文链接](https://ge.lzu.edu.cn/xueweishouyu/guizhangzhidu/lunwenguanli/2020/1223/158945.html)）编写，关键规定摘录如下：

- 博士学位论文答辩委员会由 5–7 人组成，其中校外专家 **至少 2 人**
- 硕士学位论文答辩委员会由 3–5 人组成，其中校外专家 **至少 1 人**
- 答辩委员会主席须为博士生导师（博导）
- 导师不得担任答辩委员会委员，但须列席
- 答辩表决采用无记名投票，同意票 ≥ 2/3 方为通过

其余以学校最新文件为准。

## 快速理解：答辩秘书是干什么的

答辩秘书不是答辩委员会成员，不参与学术评议，而是负责整个答辩过程的行政和记录工作。核心职责：

1. **预答辩期间**：组织预答辩、记录委员意见、将反馈整理给答辩人
2. **正式答辩前**：协助准备材料、协调时间地点、发送邀请函
3. **答辩当天**：记录答辩过程、汇总决议、处理突发状况
4. **答辩后**：整理归档所有材料，确保符合学位办要求
